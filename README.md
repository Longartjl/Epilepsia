# Epilepsia
Este repositorio recopila un conjunto de herramientas computacionales y modelos matemáticos diseñados para estudiar la **epileptología computacional**. El objetivo central es tender un puente entre la teoría de sistemas dinámicos no lineales (como el análisis de bifurcaciones y ruido estocástico), la farmacocinética y el aprendizaje automático aplicado a señales de electroencefalografía (EEG), simulando el comportamiento de redes neuronales y la transición hacia crisis epilépticas (*ictogénesis*).
